# Technical risk register

| Risk                                                        | Probability | Impact   | Early signal                           | Mitigation/gate                                                                              | Status                                  |
| ----------------------------------------------------------- | ----------- | -------- | -------------------------------------- | -------------------------------------------------------------------------------------------- | --------------------------------------- |
| Blob credentials, signed constraints or browser PUT fail    | Medium      | High     | Token/presign error or 403 in lab      | Private store, OIDC on Vercel, scoped five-minute URL, live Preview gate                     | Code-complete; live Vercel Blob pending |
| Uploaded file spoofs MIME or carries EXIF/GPS               | High        | Critical | Decoder mismatch/metadata remains      | Bounded Sharp decode, allowlist, WebP re-encode, tests                                       | Automated mitigation in place           |
| Mongo pool is recreated or rejected promise poisons process | Medium      | High     | Connection growth/readiness stays down | Process cache, rejected-promise recovery, read/write probe                                   | Automated; live preview pending         |
| Template reads host state or makes arbitrary requests       | Medium      | Critical | same-origin access/network calls       | iframe `allow-scripts` only, opaque origin, source + schema checks, CSP `connect-src 'none'` | Chrome automation in place              |
| Audio fails in Safari/WebView                               | High        | High     | rejected `play()`/no sound after tap   | Explicit user gesture, visible fallback, manual device matrix                                | Chrome-first exception; mobile pending  |
| Preview configuration leaks production data/secrets         | Medium      | Critical | prod URI/bucket reused in PR           | Separate Atlas DB/bucket prefix, Vercel environment scope, no secret logs                    | Runbook defined; setup pending          |
| Gift schema becomes arbitrary                               | Medium      | High     | duplicate validators/invariants        | Zod canonical schemas, repository boundary, migrations                                       | Foundation in place                     |
| Template bundle grows with each design                      | High        | High     | Viewer JS/media regression             | Independent workspace, measured manifest budgets, CI failure                                 | Gate in place                           |
| Auth implementation permits IDOR                            | Medium      | Critical | route-only UI checks                   | Better Auth ADR, DAL, ownership in application use cases, authorization tests                | Sprint 1 gate                           |
| Browser support is inferred from emulation                  | High        | High     | desktop green/mobile field failures    | Physical-device matrix before Viewer exit/pilot                                              | Explicitly deferred, not closed         |

Risk owner is the Tech Lead until a sprint story assigns a named owner. A risk may be closed only by
linked automated evidence or a dated manual verification record; documentation alone is not proof.
